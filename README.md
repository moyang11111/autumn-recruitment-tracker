# 秋招资源汇总平台

这是一个面向应届生和求职者的静态秋招信息聚合与投递进度管理工具。它集中展示央国企、私企和外企的校园招聘信息，并允许用户记录每条招聘信息的投递状态。

## 快速开始

项目不依赖构建工具和第三方包，直接双击根目录的 `index.html` 即可打开。若浏览器对本地文件的脚本或下载行为有限制，可以在项目根目录启动一个可选的本地静态服务器：

```bash
python -m http.server 5173
```

然后访问 <http://localhost:5173/>。也可以使用任意其他静态文件服务器，平台不需要后端服务。

## 数据与本地持久化

- `data.js` 提供 `globalThis.INITIAL_RECRUITMENT_DATA`，包含 24 条可直接用于演示的初始化记录。
- 所有日期、状态和招聘链接都是演示数据；日期是模拟的 2026 年 8—10 月秋招时间，请务必以企业官方招聘页面为准。
- 首次打开时，前端应将初始化数组复制到 localStorage；用户后续修改状态时写回 `autumn-recruitment-tracker:v1`。这样刷新页面不会丢失投递记录。
- “恢复示例数据”一类操作只应清除该 key 并重新复制初始化数组，不会影响浏览器其他站点的数据。
- 每次状态改变都要同步写入该记录的 `statusUpdatedAt`（ISO 8601 时间字符串），列表可以据此展示“更新于”时间并支持按最近更新排序。

## 导出 CSV 并在 Excel 中打开

页面中的“导出 CSV”会将当前数据导出为 UTF-8 CSV。使用 Excel 时，推荐选择“数据 → 自文本/CSV”，编码选择 `UTF-8`，分隔符选择“逗号”，再加载文件。这样中文企业名、岗位类别和状态不会乱码。

如果使用 Excel 直接双击 CSV，较新版本通常会自动识别 UTF-8；若出现乱码，请改用“数据 → 从文本/CSV”导入。数组字段（例如多个岗位类别）建议在同一单元格中用 `、` 连接。

## 数据结构

每条 `INITIAL_RECRUITMENT_DATA` 记录的字段如下：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 全局唯一的招聘记录 ID |
| `companyName` | string | 企业名称 |
| `companyType` | enum | `央国企`、`私企`、`外企`、`事业单位`、`其他` |
| `openDate` | `YYYY-MM-DD` | 秋招开放日期；演示日期 |
| `deadline` | `YYYY-MM-DD` | 秋招截止日期；演示日期 |
| `province` | string | 公司所在省份/直辖市 |
| `city` | string | 公司所在城市 |
| `categories` | string[] | 招聘岗位类别，可为空数组但示例均提供类别 |
| `campusUrl` | string | 校招官网或企业官方招聘链接 |
| `status` | enum | 当前简历投递状态 |
| `statusUpdatedAt` | ISO 8601 string | 最近一次状态变更时间 |
| `isDemo` | boolean | 是否为演示数据；初始化记录均为 `true` |

同时，数据文件还暴露了 `globalThis.RECRUITMENT_STATUS_OPTIONS`、`globalThis.RECRUITMENT_COMPANY_TYPES` 和 `globalThis.RECRUITMENT_DATA_META`，方便界面复用枚举和演示数据提示。

## 投递状态字段

`status` 只能使用以下值，界面建议为每个值使用独立颜色标签，并允许用户手动更新：

1. `未投递`
2. `已投递`
3. `筛选中`
4. `笔试 / 测评中`
5. `面试中`
6. `已发 offer`
7. `终止流程 / 已淘汰`
8. `已接受 / 已拒绝 offer`

## 校验

无需安装依赖，运行：

```bash
npm test
```

该命令会检查数据数量、必需企业、ID 唯一性、日期、URL、枚举字段和 Node 可加载性。如果应用文件已经集成到同一目录，还会自动检查 `index.html` 及常见脚本/样式入口和关键页面挂钩；也可以用下面的严格集成检查明确要求应用文件存在：

```bash
npm run test:integration
```

集成检查只匹配语义性的文本、常见 ID/data 属性和常见资源文件名，不要求固定 HTML 排版，便于 UI 层调整结构。

## 后续扩展建议

- 增加用户登录、个人简历/收藏夹，以及多设备数据同步。
- 用后端数据库替换 localStorage，支持多用户、权限和操作日志。
- 接入经过授权的招聘信息采集任务或企业官方 RSS/API，自动更新开放/截止时间，并记录来源和抓取时间。
- 增加截止日期提醒、微信/邮件通知、日历订阅和批量状态更新。
- 增加岗位去重、链接可用性检查、数据审核和“官方来源”标记，降低过期或误导信息风险。
- 增加按企业性质、城市、岗位类别和时间的统计趋势，以及 CSV/JSON 双向导入导出。

> 提醒：示例数据只用于演示产品交互，不构成招聘承诺或求职建议；投递前请核验企业官方公告和招聘链接。
